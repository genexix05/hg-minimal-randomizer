HeartGold Minimal Randomizer
============================

1. Extract this ZIP anywhere.
2. Run the launcher for your OS:
   - Windows: launcher_WINDOWS.bat
   - macOS:   launcher_MAC.command
   - Linux:   launcher_UNIX.sh
3. Open your HeartGold Minimal ROM, randomize, save a NEW ROM.

You need Java installed (same as Universal Pokemon Randomizer ZX).

This package does NOT include any Nintendo ROMs.
